# Skill Gap Analyzer

## Project Overview

Skill Gap Analyzer is a Java-based console application that helps students understand the skills required for their desired career.

The project compares the student's current skills with the skills required for a selected career. It calculates the skill match percentage and shows the missing skills that the student needs to learn.

## Objectives

- Analyze the current skills of a student.
- Compare current skills with career requirements.
- Calculate the skill match percentage.
- Identify missing skills.
- Provide basic learning suggestions.

1. Enter student details.
2. Select a career goal.
3. Enter current skills.
4. Compare current skills with required skills.
5. Calculate skill match percentage.
6. Display available and missing skills.
7. Show basic analysis.
